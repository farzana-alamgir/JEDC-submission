# Calibrated model at sigma_oil = 0.30 — ready-to-compile sources

Self-contained snapshots, one per economy, with every calibrated parameter
baked in. Nothing to edit: compile and run.

    gfortran -O3 -march=native -o solver oil_prod_CES_bm.f90
    ./solver

One economy takes about 30 seconds and writes ~190 MB of `graphs_*.txt` into
the working directory, so run each in its own folder.

## Calibration

| parameter | value | |
|---|---|---|
| `theta` | −2.33333333 | `sigma_oil = 1/(1−theta) = 0.30` |
| `alpha` | 0.000188992 | set so the oil share is 9% of GDP; **not** the oil share itself |
| `beta` | 0.964 | |
| `d0` | −0.246 | unchanged from the submission |
| `d1` | 0.37 | |
| grid | `p_num = 7`, per-state Rouwenhorst (`use_common_p_grid = .false.`) | the submitted grid construction |

Fit: mean spread 3.99 (target 4.1), sd 2.25 (2.0), debt/GDP 33.41 (34.0),
oil/GDP 8.73% (9.0%).

## The six economies

| file | what it is |
|---|---|
| `oil_prod_CES_bm.f90` | **benchmark** — full stochastic volatility |
| `oil_prod_CES_mp.f90` | mean-preserving: volatility acts only through dispersion |
| `oil_prod_CES_intermediate.f90` | constant volatility at the variance-matching level |
| `oil_prod_CES_basic.f90` | constant price, pinned at the theoretical ergodic mean |
| `oil_prod_CES_intermediate_matched.f90` | as `intermediate`, re-pinned so simulated `E[p]` equals the benchmark's |
| `oil_prod_CES_basic_matched.f90` | as `basic`, same re-pinning |

**Use the `_matched` pair for any welfare or spread decomposition.** The
unmatched versions face oil 1.7% and 3.0% dearer than the benchmark, which at
`sigma_oil = 0.30` is enough to invert the welfare ranking. See
`results/FINAL_CALIBRATION.md`.

## Provenance

Generated by `model/solve_final.sh`, which applies the calibration to the
single master source `model/oil_prod_CES.f90`:

    ./solve_final.sh runs_final 0.000188992 -2.33333333 0.964 -0.246 0.37

**Edit the master, not these.** They are snapshots for convenience; the master
is where the economies are kept in sync by compile-time switch rather than by
forking. Regenerate with the command above if the master changes.

## Figures

MATLAB, in `model/figures_pipeline/`:

    cd model/figures_pipeline
    CONTRAST_MODE=fraction bash run_all_final_matched.sh

That stages each run directory in turn, runs `script_intermediate.m`,
`script_basic.m` and `script_bm.m`, and writes all ten `FIGURE*.jpg`.
`script_bm.m` draws every figure and loads the other two workspaces for
FIGURE2 and FIGURE7, which is why it must run last. Point the `stage` lines at
your own solved directories if they are not under `model/runs_final/`.

Supporting files: `fastload.m` (textscan reader for the large ASCII dumps),
`ink.m` / `ink_optionA.m` (blank-panel detector).
