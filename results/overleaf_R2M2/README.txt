Overleaf package: response to R2 Major 2
----------------------------------------
Upload response_R2M2.tex to a new Overleaf project and compile with pdfLaTeX.
No figures are required. Standard packages only (geometry, booktabs, amsmath,
framed, hyperref, microtype).

To paste into an existing response document instead, copy everything between
    % =========================== BODY BEGINS ===
    % ============================ BODY ENDS ====
and make sure the host document loads booktabs and framed.
